# Rustpress edition catalog

Every edition pressed on [press.mazzeleczzare.com](https://press.mazzeleczzare.com/), in order.
A pressing is a sealed, byte-exact bundle: `rustpress verify --release <label> --expect <seal>`
re-checks it without any network access. Each seal below is the SHA-256 of the
release descriptor; retain them independently of this repository.

## Inspecting a pressing

```sh
cargo run --locked -- verify --site site --release commissioning-007 \
  --expect 7cbff29e47662f4b362a7da4ec1415cab8ad48f628471ba64ae3d43db2e78544
```

The seal is an inventory hash, not a signature: whoever rewrites the whole
bundle can forge one. The digest above is retained outside the bundle as the
independent check.
