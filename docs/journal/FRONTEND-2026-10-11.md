independent letterpress direction: warm paper, dark ink, oxide red, Cormorant

and file identity from authorship or truth.

fonts/styles, includes recovery links, and is marked noindex. A local SVG favicon
belongs to the trusted site template (the corpus policy remains unchanged).
Local fonts now import only Latin subsets, reducing the sealed inventory from 59
to 36 files. No dependencies, runtime adapter, or authored scripts were added.

## Delivery transformations found during verification

The live HTML does **not** match the sealed HTML byte for byte. Responses include
an edge-injected `/.webmcp/bridge.js` module, and some include a Cloudflare challenge
script. Both corpus HTML routes had different HTTP hashes from their recorded
sealed file hashes; the corpus CSS matched. Cloudflare also prepends managed
content signals/crawler rules to robots.txt. Python urllib's default client got
HTTP 403 on the homepage; curl and Chrome loaded it successfully.

The frontend's fingerprint label was corrected to **Sealed file**, and its process
copy now describes reviewed files as the **deployment payload**. It no longer
promises that transformed HTTP responses equal those files. The manifest itself
still records the sealed output. No Cloudflare security, bot, content-signal, or
WebMCP settings were changed. A separate delivery review is needed before claiming
end-to-end HTTP byte identity or a script-free live response.
